## S^7 SU(2)^3 One-Parameter ODE

The most recent technical object was a one-parameter ODE shooting family.

The Podesta reduction uses functions:

```text
f0 = t h0
f1 = t^4 h1
f2 = h2
f3 = t^2 h3
f4 = t^2 h4
h4 = -h3 - h0^2/6
```

Smooth left-end initial data:

```text
h0(0) = a
h1(0) = 27/4
h2(0) = -a^3/27
h3(0) = 3a
```

Here `a` is the real shooting parameter. It is not the interval length. The
known compact values in this normalization are:

```text
round:    a = -36
squashed: a = 108/5
```

The finite h-ODE has the form:

```text
h0' = A0/t + B0
h1' = A1/t + B1
h2' = B2
h3' = A3/t + B3
```

with:

```text
A0 = -h0 - 3 h2 h3^2 / h0^4
A1 = -4 h1 + h3^3 / h0^3
A3 = -2 h3 + 6 h0

B0 = -3/(2 h0^4) * ( t(h3-h4)(h1 h2+h3 h4) - 2 t^3 h1 h4^2 )
B1 =  t/(2 h0^3) * ( h1^2 h2 - 3 h1 h3 h4 )
B2 =  t/h0^3 * ( h4(h2 h3 - t^2 h4^2)
                  - 1/2 h2(h1 h2 - h3 h4) )
B3 =  t/(2 h0^3) * ( h1 h2 h3 + h3^2 h4 - 2 t^2 h1 h4^2 )
```

Scaled variables used for large-|a| analysis:

```text
h0 = a x0
h1 = x1
h2 = a^3 x2
h3 = a x3
b = 1/a
p = x0
```

### Closure Condition

To check if a solution closes up, integrate the smooth left-end solution until
the first terminal time `T_a` where `h0=0`, equivalently `x0=0`.

For the standard `K_-` closure with `f1 != 0`, the terminal requirements are:

```text
f0 = f2 = f3 = f4 = 0
```

In h variables this is equivalent to:

```text
h2(T_a) = 0
h3(T_a) = 0
```

because `h4` then follows from the algebraic relation.

In scaled variables the closure requirements are:

```text
x2(T_a) = 0
x3(T_a) = 0
```

The original scalar shooting error considered was roughly:

```text
D_x2(a) = x2(T_a)
```

This was not ideal because the large-|a| limiting signal was small, around
`0.0059`. A stronger defect was:

```text
D_x3(a) = x3(T_a)
```

whose large-|a| limiting signal was about `-1.17`.

Another candidate was:

```text
C = x1*x2 - p^2*x3/6
```

and combinations such as `x3(T)^2 + C(T)^2`.

### Large-|a| Numerics

Observed large-|a| behavior:

```text
T_a -> T_infty approximately 3.5975
```

Both signs `a -> +infinity` and `a -> -infinity` appeared to approach the same
finite terminal time.

A robust p-time computation from `p=0.2` with `t_step=2.5e-5` gave:

```text
T      approximately 3.5975146936
x1     approximately 9.0813782
x2     approximately 0.00596075
x3     approximately -1.16730204
```

Important distinction discussed:

- `x_{3,a}(T_a)` is the terminal value at the a-dependent terminal time.
- `x_{3,a}(T_infty)` is a fixed-time/preterminal question and is only literally
  defined when the trajectory exists up to `T_infty`.

Conceptually, the preterminal limit is:

```text
lim |a| -> infinity x_{3,a}(T_infty)
  = x_{3,infty}(T_infty)
  approximately -1.17
```

The difference between `x_{3,a}(T_infty)` and `x_{3,a}(T_a)` should go to zero
if the terminal layer is regular in p-time and the p-time terminal variation
tends to zero.


## Literature Question Left Open

Right before the context window filled, the user asked whether the literature
has precedents for global exclusion in ODE shooting problems and how those
proofs work.

This was not fully answered in the old thread. A new thread should browse and
verify sources before giving a sourced answer.

Likely relevant proof patterns to check:

- invariant regions and first-crossing/barrier arguments for shooting systems
- monotonicity or energy/integral identities
- separator/section arguments for stable and unstable manifold nonintersection
- validated numerics using interval ODE integration, interval Newton/Krawczyk,
  radii polynomials, or Lohner/Taylor-model methods
- cohomogeneity-one Einstein non-existence papers, including recent work that
  uses polynomial flow and barrier regions

The main strategic lesson from the old thread: global exclusion is usually not
proved by sampling a scalar endpoint residual alone. The successful patterns
tend to combine a good coordinate compactification with barriers, integral
identities, or rigorous parameter-box covering.
